# 企业员工手册数据清洗与智能问答知识库平台

一个基于 **RAG（检索增强生成）** 的企业文档问答系统：上传员工手册后，
系统自动完成数据清洗、分块、向量化入库；员工用自然语言提问即可获得准确回答，
并附带原文出处。

项目重点在 **数据清洗** 和 **可溯源问答** 两个环节，适合演示真实企业文档场景下的 RAG 落地。

---

## 一、功能特性

| 功能 | 说明 |
|---|---|
| 🧹 数据清洗 | 五步流水线：格式归一、噪声过滤、敏感信息脱敏、按行去重 |
| 📚 知识库构建 | 文本分块 → 向量化 → 存入 Chroma 持久化 |
| 🔍 语义检索 | 按语义相似度召回 Top-K 文本块 |
| 💬 智能问答 | Qwen 依据检索结果生成回答，资料没有就明确说明 |
| 📎 引用溯源 | 每条回答附带命中的文档块，便于核对 |
| 🗣️ 多轮对话 | 保留最近 6 轮上下文 |
| 🖥️ 双页面界面 | 问答页 + 知识库管理页（上传、清洗预览、参数调节） |

## 三、工作流程

### 构建知识库

```
上传文档（txt / md / pdf）
        │
        ▼  loader 读取
原始文本
        │
        ▼  cleaner 清洗（五步）
干净文本
        │
        ▼  splitter 分块（定长 + 重叠）
文本块列表
        │
        ▼  embedder 向量化
向量
        │
        ▼  store 写入
Chroma 持久化向量库
```

### 问答

```
用户问题
        │
        ▼  Chroma 语义检索 Top-K
相关文本块
        │
        ▼  拼装上下文
Prompt（System 含参考资料）
        │
        ▼  qwen-plus 流式生成
回答文字 + 引用出处
```

## 六、使用说明

### 第一步：导入知识库

1. 进入左侧「知识库管理」页面
2. 上传手册文件，或点击「导入示例文档」
3. 系统自动清洗，可切换标签页对比清洗前后
4. 调整分块大小和重叠字数（默认 300 / 50）
5. 点击「导入知识库」

### 第二步：开始提问

1. 回到首页
2. 在输入框提问，或点击示例问题
3. 回答下方会显示引用出处（📎 文档名 · 第 N 块）

**示例问题：**

- 出差报销需要多久内提交？
- 迟到多久算旷工？
- 报销超过 5000 元谁审批？
- 公司年假有几天？（手册里没有，模型会明确说查不到）

## 七、核心实现说明

### 1. 数据清洗流水线（`core/cleaner.py`）

按顺序执行五步，顺序不能乱：

| 步骤 | 做法 | 作用 |
|---|---|---|
| 1. 统一换行符 | `\r\n`、`\r` → `\n` | 兼容不同系统文档 |
| 2. 噪声过滤 | 正则匹配页码、目录点线、纯符号行 | 去掉无效内容 |
| 3. 空白归一 | 连续空格合并、连续空行压缩 | 减少无用字符 |
| 4. 敏感信息脱敏 | 手机号、身份证、邮箱正则替换 | 保护隐私 |
| 5. 按行去重 | 内容 MD5 + 集合判重 | 去掉重复条款，O(1) 查询 |

脱敏效果示例：

```
13812345678      →  138****5678
110101199003071234 → 110101********1234
zhangsan@example.com → z***@example.com
```

### 2. 文本分块（`core/splitter.py`）

- 切分顺序：段落 → 换行 → 句号/问号/分号/逗号 → 字符
- 默认每块 300 字，相邻块重叠 50 字
- **为什么要重叠**：切分点可能落在一句话中间，重叠能让相邻块共享边界信息，
  避免关键内容被切断后检索不到

### 3. 向量检索（`core/store.py`）

- 每个文本块转成向量后存入 Chroma
- 检索时计算余弦相似度，返回 Top-K
- 返回的分数**越小越相关**
- 每个块保留 `doc_name` 和 `chunk_index` 元数据，用于展示引用

### 4. 检索问答链（`core/chain.py`）

```python
chain = PROMPT | get_llm(streaming=True) | StrOutputParser()
stream = chain.stream({
    "context": context,
    "question": question,
    "history": history,
})
```

防幻觉设计：

- System Prompt 明确要求「只依据参考资料回答」
- 资料中没有答案时，必须回答「手册中未找到相关内容」
- `temperature=0.1`，降低模型自由发挥

### 5. 多轮对话

- 历史消息通过 `MessagesPlaceholder` 传入
- 只保留最近 6 条，控制 token 消耗
- 界面传入历史时排除当前问题，避免重复

## 九、常见问题

**Q：上传 PDF 提示无法提取文字？**
A：可能是扫描件（图片型 PDF），需要先做 OCR。本项目只解析文字型 PDF。

**Q：回答总是「未找到相关内容」？**
A：检查知识库是否有数据、问题是否与手册内容相关；可以调大 Top-K 试试。

**Q：想更换文档？**
A：在「知识库管理」页先清空知识库，再上传新文档。

**Q：向量库存在哪里？**
A：项目目录下的 `chroma_db/`，已被 `.gitignore` 排除，不会提交到仓库。

**Q：分块大小怎么调？**
A：文档内容长、问题偏细节时用小块（200~300）；问题偏概括时用大块（500~800）。
