# AI 语音智能客服助手

一个面向客服场景的 **语音问答系统**：用户按住麦克风说出问题，系统自动识别成文字，
检索 FAQ 知识库后生成回答，并用语音朗读出来。

适合用来演示「语音识别 + RAG 检索 + 语音合成」的完整链路。

---

## 一、功能特性

| 功能 | 说明 |
|---|---|
| 🎙️ 语音输入 | 浏览器内录音，自动转写成文字（Streamlit `st.audio_input`） |
| 📚 FAQ 知识库 | 内置 10 条常见问题，语义检索最相关的 3 条作为参考 |
| 💬 智能回答 | Qwen 依据 FAQ 生成客服回复，资料中没有的会建议转人工，不编造 |
| 🔊 语音播报 | 回答自动合成为语音播放，可在侧边栏关闭 |
| ⌨️ 文字兜底 | 没有麦克风时可以直接打字提问 |
| 🗣️ 多轮对话 | 保留最近 6 轮上下文，支持连续追问 |
| 🔍 引用查看 | 可选显示本次回答匹配到的 FAQ 条目 |

---

## 二、技术栈

| 环节 | 技术 | 说明 |
|---|---|---|
| Web 界面 | Streamlit 1.67 | 快速搭建交互界面，原生支持录音组件 |
| 语音识别 | DashScope `qwen3-omni-flash` | 多模态模型，直接理解音频内容 |
| 语音合成 | DashScope `cosyvoice-v2` | 把回答文字合成为 mp3 音频 |
| 对话生成 | DashScope `qwen-plus` | 生成客服回答 |
| 检索框架 | LangChain（LCEL） | 编排「检索 → Prompt → 模型 → 解析」 |
| 向量数据库 | Chroma | 本地持久化向量库 |
| 向量化 | DashScope `text-embedding-v4` | 把文本编码为向量 |

## 五、快速开始

### 1. 环境准备

需要 Python 3.12 及以上。

```bash
# 进入项目目录
cd AI语音智能客服助手

# 创建虚拟环境
python -m venv .venv

# 激活（Windows）
.venv\Scripts\activate
```

### 2. 安装依赖

```bash
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 3. 配置 API Key

```bash
copy .env.example .env
```

用记事本打开 `.env`，填入阿里云 DashScope 的 Key：

```
DASHSCOPE_API_KEY=sk-xxxxxxxxxxxxxxxx
```

> Key 获取地址：https://dashscope.console.aliyun.com/apiKey
> 注意：`.env` 已被 `.gitignore` 排除，不会提交到仓库。

### 4. 启动应用

```bash
streamlit run app.py
```

浏览器会自动打开 `http://localhost:8501`。首次启动会自动把 `data/faq.txt` 导入向量库。

## 六、使用说明

1. 浏览器弹出麦克风权限请求，点击**允许**
2. 点击录音按钮，按住说话，说完松开
3. 系统自动识别语音 → 检索 FAQ → 生成回答 → 播放语音
4. 也可以在底部输入框直接打字提问

**示例问题：**

- 我的快递三天了还没到，怎么查物流？
- 收到的商品坏了，怎么退换？
- 怎么开发票？
- 支持哪些支付方式？
- 退款多久到账？

**侧边栏设置：**

| 选项 | 作用 |
|---|---|
| 语音播报 | 关闭后只显示文字，不合成语音（省调用次数） |
| 显示匹配的 FAQ | 显示本次回答参考了哪些 FAQ 条目 |
| 清空对话 | 重置当前会话 |

## 七、核心实现说明

### 1. 语音识别（`core/asr.py`）

- Streamlit 录音返回 WAV 字节流，先写入临时文件
- 转成 `file:///` 路径传给 DashScope 多模态接口
- 提示词要求「只输出转写文字」，避免模型附带解释
- 识别完成立即删除临时文件

### 2. FAQ 知识库（`core/kb.py`）

- FAQ 按 `Q:` 开头切分成一条条问答，每条作为一个独立文本块
- 每条问答单独向量化，避免问题和答案被切散
- 知识库为空时自动导入，已有数据不重复导入

### 3. 防幻觉设计（`core/chat.py`）

```
System Prompt 写死三条约束：
1. 回答必须完全来自参考资料
2. 找不到答案时只能回答「暂时查不到，建议转接人工客服」
3. 严禁推测或编造地址、电话、价格、政策等信息
```

配合 `temperature=0.1`，大幅降低模型自由发挥。

### 4. 语音合成（`core/tts.py`）

- 合成前去掉 Markdown 符号（`*`、`#`、`` ` ``），避免朗读出符号
- 回答长度控制在三句话以内，适合语音播报

## 八、常见问题

**Q：录音按钮没有反应？**
A：检查浏览器是否允许了麦克风权限；Streamlit 需要 1.38 及以上版本。

**Q：语音识别失败？**
A：检查 `.env` 中的 `DASHSCOPE_API_KEY` 是否正确、账户是否有余额。

**Q：回答总是「暂时查不到」？**
A：说明问题与 FAQ 内容不相关。可以编辑 `data/faq.txt` 增加知识，然后删除 `chroma_db/` 目录重启，会自动重新导入。

**Q：如何替换成自己的 FAQ？**
A：直接修改 `data/faq.txt`，保持 `Q: 问题` / `A: 答案` 的格式，删除 `chroma_db/` 后重启即可。
